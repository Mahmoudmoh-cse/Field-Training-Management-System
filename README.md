# Field Training Management System

A relational-database project for managing university field-training and internship workflows.

## Stakeholders

- Students
- Internal mentors
- External mentors
- Evaluators
- Internship coordinators
- Administrators
- Partner organizations

## Features

### Students
- Register for internships
- Submit internship reports
- Receive mentor and evaluator feedback

### Coordinators
- Approve or reject organizations
- Assign mentors
- Coordinate internships

### Mentors & Evaluators
- Track student progress
- Review reports
- Submit evaluations and feedback

### Administrators
- Manage users, students, mentors, and organizations
- Monitor weekly and final submissions
- Generate reports and maintain data integrity

## Database Design

Core entities include users, students, mentors, coordinators, evaluators, internships, organizations, reports, and evaluations.

The schema is normalized to **Third Normal Form (3NF)**.

## Tech Stack

- SQL
- MySQL / MariaDB
- Stored procedures
- Views
- ERD / EERD modeling
- Database normalization
